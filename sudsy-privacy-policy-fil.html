Patakaran sa Privacy

Sudsy: Idle Car Wash Tycoon · Bersyon 1.0 · May bisa simula Nobyembre 21, 2026

Ipinapaliwanag ng patakarang ito kung anong data ang pinoproseso ng larong Sudsy: Idle Car Wash Tycoon (ang "laro"), kung bakit, at kung ano ang puwede mong gawin tungkol dito. Kung may pagkakaiba ang isang salin sa bersyong Ingles, ang bersyong Ingles ang masusunod.

Sino kami

Ang laro ay inilalathala ng Lagom Labs ("kami"). Contact: lagomlabs@gmail.com.

Ano ang kinokolekta ng laro

  • Mga event sa laro (Firebase Analytics). Mga event gaya ng mga natapos na paghuhugas (kotse, kalidad, mano-mano o ng tauhan, tagal), mga upgrade ng istasyon, pagkuha ng tauhan, mga live event, mga hakbang ng tutorial, mga alok at pagkumpleto ng rewarded ad, mga pagtingin sa shop at mga pagbili (product ID), mga pagbenta ng franchise, mga nakolektang offline na kita, mga resulta ng cloud save, at pahintulot at pagbukas ng notification, kasama ang isang random na app-instance ID at pangunahing impormasyon ng device at app (modelo, bersyon ng OS, wika, bansang hinango mula sa IP address, bersyon ng app) at, sa unang pagbukas, ang Google Play install referrer (kung aling page sa store o campaign ang nagdala sa pag-install). Itinatala rin namin kapag humihingi ang laro ng rating sa store. Naka-off ang pagkolekta hanggang pahintulutan ito sa hakbang ng pahintulot (consent), at puwede mo itong i-off anumang oras sa Mga Setting → Istatistika ng paggamit. Hindi kinokolekta ng Analytics ang iyong advertising ID o Android ID.
  • Mga crash report (Firebase Crashlytics). Kapag nag-crash ang laro: ang crash trace, modelo ng device, bersyon ng OS, libreng memory at isang random na Crashlytics installation ID, para mahanap at maayos ang mga bug.
  • Mga remote setting (Firebase Remote Config). Nagda-download ang laro ng mga value para sa balanse ng laro; gumagamit ito ng isang random na Firebase installation ID.
  • Mga ad (Google AdMob). Rewarded ad lang ang ipinapakita ng laro, at ikaw ang pumipili kung manonood ka. Para maipakita ang mga ito, pinoproseso ng AdMob ang advertising ID ng iyong device, IP address at impormasyon ng device. Sa EEA, sa UK at sa iba pang rehiyon kung saan ito kinakailangan, tatanungin ka muna ng consent form ng Google; kung wala ang iyong pahintulot, hindi personalized ang mga ad.
  • Cloud save (Google Play Games Services). Kung naka-sign in ka sa Google Play Games, ang iyong Play Games player ID at progreso sa laro (isang save file) ay iniimbak sa iyong Google account para maituloy mo ito sa ibang device.
  • Mga pagbili (Google Play Billing). Ang Google Play ang buong humahawak sa mga bayad. Isang record ng pagbili lang ang natatanggap ng laro (product ID, order at purchase token) at hindi nito kailanman nakikita ang mga detalye ng iyong card o bangko.
  • Mga notification (Firebase Cloud Messaging). Kung papayagan mo lang ang mga notification, makakakuha ang device ng messaging token at isu-subscribe ito sa isang news topic para sa wika ng iyong laro (halimbawa "lang_fil"). Ang mga paalala gaya ng "puno na ang cash box" ay pinaplano sa iyong device at walang ipinapadalang data.
  • Mga rating (Google Play In-App Review). Puwedeng ipakita ng laro ang rating card ng Google Play pagkatapos ng isang masayang sandali. Ang Google ang nagpapasya kung lalabas ito; hindi kailanman malalaman ng laro kung nag-rate ka o kung paano ka nag-rate.
  • Sa iyong device. Ang iyong progreso at mga setting ay iniimbak sa device.

Ano ang hindi kinokolekta ng laro

Ang iyong pangalan, e-mail address, numero ng telepono, eksaktong lokasyon, mga contact, mga larawan, mga file o mikropono. Hindi humihingi ang laro ng mga pahintulot na ito. Ang laro mismo ay humihingi ng: internet access, network state, vibration, mga notification (Android 13+, opsyonal), pag-restart ng mga paalala pagkatapos ng reboot, ang advertising ID (para sa mga ad) at Google Play billing. Idinadagdag ng mga library ng Google sa loob ng laro ang: pagpapanatiling gising sandali ng device para sa mga background task, pagtanggap ng push messages, pagbasa ng Play install referrer, ang mga Android ad-services attribution at ad ID API, ang basic phone state (uri ng network, ginagamit ng mga ad) at isang foreground service para sa background na trabaho ng Google. Wala sa mga ito ang humihingi sa iyo ng anuman sa screen at wala sa mga ito ang nagbibigay ng access sa iyong mga tawag, mensahe o file.

Bakit namin ito ginagamit

Para patakbuhin ang laro at i-save ang iyong progreso, para maibalik ito sa bagong device, para mahanap at maayos ang mga crash, para mabalanse ang laro, para maipakita ang mga rewarded ad na pinipili mo at para maihatid ang binibili mo.

Mga third party

Lahat ng serbisyo sa itaas ay ibinibigay ng Google: Firebase Analytics, Crashlytics, Remote Config at Cloud Messaging (firebase.google.com/support/privacy), AdMob (policies.google.com/technologies/ads), Google Play Games Services at Google Play Billing (policies.google.com/privacy). Hindi namin ibinebenta ang iyong data at hindi namin ito ibinabahagi sa iba.

Pahintulot at ang iyong mga pagpipilian

  • Lumalabas ang consent form sa unang pagbukas kung saan ito kinakailangan; buksan itong muli anumang oras sa Mga Setting → Mga setting ng privacy.
  • I-off ang istatistika ng paggamit sa Mga Setting → Istatistika ng paggamit.
  • I-off ang mga notification ayon sa channel sa Mga Setting o sa mga setting ng Android.
  • Mag-opt out sa mga personalized na ad sa mga setting ng iyong Android (Google → Mga Ad).

Pag-iingat at pagbura ng data

  • Binubura ng Mga Setting → Burahin ang data ko ang progreso sa device na ito at sa iyong Play Games cloud save, binubura ang notification token at nire-reset ang iyong analytics ID. Nananatili ang mga binili sa iyong Google account.
  • Iniimbak ang analytics data nang hanggang 14 na buwan lang; ang mga crash report nang 90 araw.
  • Para hilingin sa amin na burahin ang data na maiuugnay namin sa iyo, sumulat sa lagomlabs@gmail.com (isama ang iyong Play Games player name kung gumagamit ka ng cloud save). Sumasagot kami sa loob ng 30 araw.

Mga bata

Ang laro ay hindi para sa mga batang wala pang 13 taong gulang at naka-rate para sa edad 13 pataas.

Ang iyong mga karapatan

Depende sa kung saan ka nakatira (halimbawa sa ilalim ng KVKK ng Turkey, GDPR ng EU/UK o CCPA/CPRA ng California), may karapatan kang i-access, itama, burahin o ilipat ang iyong data, tumutol sa o limitahan ang pagproseso at bawiin ang pahintulot. Sumulat sa lagomlabs@gmail.com. Puwede ka ring magreklamo sa iyong awtoridad sa proteksyon ng data.

Mga pagbabago

Ia-update namin ang patakarang ito kapag binago ng laro ang pinoproseso nito. Nasa itaas ang bersyon at petsa ng pagkakabisa; ang mahahalagang pagbabago ay inaanunsyo sa laro.
