Sudsy: Idle Car Wash Tycoon · Versi 1.0 · Berlaku sejak 21 November 2026

Kebijakan ini menjelaskan data apa yang diproses oleh game Sudsy: Idle Car Wash Tycoon ("game"), alasannya, dan apa yang dapat kamu lakukan terkait hal itu. Jika terjemahan berbeda dari versi bahasa Inggris, versi bahasa Inggris yang berlaku.

Siapa kami

Game ini diterbitkan oleh Lagom Labs ("kami"). Kontak: lagomlabs@gmail.com.

Apa yang dikumpulkan game

  • Peristiwa game (Firebase Analytics). Peristiwa seperti cucian yang selesai (mobil, kualitas, manual atau oleh kru, durasi), peningkatan stasiun, perekrutan kru, event langsung, langkah tutorial, penawaran dan penyelesaian iklan berhadiah, kunjungan ke toko dan pembelian (ID produk), penjualan waralaba, pendapatan offline yang diambil, hasil penyimpanan cloud, serta izin dan pembukaan notifikasi, bersama dengan ID instans aplikasi acak dan informasi dasar perangkat dan aplikasi (model, versi sistem operasi, bahasa, negara yang diturunkan dari alamat IP, versi aplikasi) dan, pada saat pertama kali dijalankan, Google Play install referrer (halaman toko atau kampanye mana yang menghasilkan pemasangan). Kami juga mencatat saat game meminta rating di toko. Pengumpulan dinonaktifkan sampai langkah persetujuan mengizinkannya, dan kamu dapat menonaktifkannya kapan saja di Pengaturan → Statistik penggunaan. Analytics tidak mengumpulkan ID iklan atau Android ID kamu.
  • Laporan crash (Firebase Crashlytics). Saat game crash: jejak crash, model perangkat, versi sistem operasi, memori kosong, dan ID instalasi Crashlytics acak, untuk menemukan dan memperbaiki bug.
  • Pengaturan jarak jauh (Firebase Remote Config). Game mengunduh nilai keseimbangan game; untuk ini digunakan ID instalasi Firebase acak.
  • Iklan (Google AdMob). Game hanya menampilkan iklan berhadiah yang kamu pilih untuk ditonton. Untuk menampilkannya, AdMob memproses ID iklan perangkatmu, alamat IP, dan informasi perangkat. Di EEA, Inggris, dan wilayah lain yang mewajibkannya, formulir persetujuan Google akan bertanya kepadamu terlebih dahulu; tanpa persetujuanmu, iklan tidak dipersonalisasi.
  • Penyimpanan cloud (Google Play Games Services). Jika kamu masuk ke Google Play Games, ID pemain Play Games dan progres game-mu (file simpanan) disimpan di akun Google-mu agar kamu dapat melanjutkan di perangkat lain.
  • Pembelian (Google Play Billing). Pembayaran sepenuhnya ditangani oleh Google Play. Game hanya menerima catatan pembelian (ID produk, pesanan, dan token pembelian) dan tidak pernah melihat detail kartu atau rekening bankmu.
  • Notifikasi (Firebase Cloud Messaging). Hanya jika kamu mengizinkan notifikasi, perangkat mendapatkan token pesan dan berlangganan topik berita untuk bahasa game-mu (misalnya "lang_id"). Pengingat seperti "kotak uang penuh" dijadwalkan di perangkatmu dan tidak mengirim data apa pun.
  • Rating (Google Play In-App Review). Game dapat menampilkan kartu rating Google Play setelah momen yang menyenangkan. Google yang memutuskan apakah kartu itu muncul; game tidak pernah tahu apakah atau bagaimana kamu memberi rating.
  • Di perangkatmu. Progres dan pengaturanmu disimpan di perangkat.

Apa yang tidak dikumpulkan game

Nama, alamat e-mail, nomor telepon, lokasi akurat, kontak, foto, file, atau mikrofonmu. Game tidak meminta izin-izin ini. Game itu sendiri meminta: akses internet, status jaringan, getaran, notifikasi (Android 13+, opsional), memulai ulang pengingat setelah perangkat di-reboot, ID iklan (untuk iklan), dan penagihan Google Play. Library Google di dalam game menambahkan: menjaga perangkat tetap aktif sebentar untuk tugas latar belakang, menerima pesan push, membaca Play install referrer, API atribusi (attribution) dan ID iklan dari layanan iklan Android, status dasar ponsel (jenis jaringan, digunakan oleh iklan), dan layanan latar depan untuk pekerjaan latar belakang Google. Tidak ada satu pun yang meminta apa pun darimu di layar dan tidak ada yang memberikan akses ke panggilan, pesan, atau file-mu.

Mengapa kami menggunakannya

Untuk menjalankan game dan menyimpan progresmu, memulihkannya di perangkat baru, menemukan dan memperbaiki crash, menyeimbangkan game, menampilkan iklan berhadiah yang kamu pilih, dan mengirimkan apa yang kamu beli.

Pihak ketiga

Semua layanan di atas disediakan oleh Google: Firebase Analytics, Crashlytics, Remote Config, dan Cloud Messaging (firebase.google.com/support/privacy), AdMob (policies.google.com/technologies/ads), Google Play Games Services, dan Google Play Billing (policies.google.com/privacy). Kami tidak menjual datamu dan tidak membagikannya kepada pihak lain.

Persetujuan dan pilihanmu

  • Formulir persetujuan muncul saat pertama kali dijalankan jika diwajibkan; buka kembali kapan saja di Pengaturan → Preferensi privasi.
  • Nonaktifkan statistik penggunaan di Pengaturan → Statistik penggunaan.
  • Nonaktifkan notifikasi per saluran di Pengaturan atau di pengaturan Android.
  • Pilih untuk tidak menerima iklan yang dipersonalisasi di pengaturan Android (Google → Iklan).

Penyimpanan dan penghapusan data

  • Pengaturan → Hapus data saya menghapus progres di perangkat ini dan di penyimpanan cloud Play Games, menghapus token notifikasi, dan mengatur ulang ID analitikmu. Pembelian tetap ada di akun Google-mu.
  • Data analitik disimpan paling lama 14 bulan; laporan crash selama 90 hari.
  • Untuk meminta kami menghapus data yang dapat kami kaitkan denganmu, kirim e-mail ke lagomlabs@gmail.com (sertakan nama pemain Play Games-mu jika kamu menggunakan penyimpanan cloud). Kami menjawab dalam 30 hari.

Anak-anak

Game ini tidak ditujukan untuk anak-anak di bawah 13 tahun dan diberi rating untuk usia 13 tahun ke atas.

Hak-hakmu

Tergantung di mana kamu tinggal (misalnya berdasarkan KVKK Turki, GDPR UE/Inggris, atau CCPA/CPRA California), kamu berhak mengakses, memperbaiki, menghapus, atau memindahkan datamu, menolak atau membatasi pemrosesan, dan menarik persetujuan. Kirim e-mail ke lagomlabs@gmail.com. Kamu juga dapat mengajukan keluhan kepada otoritas pelindungan data di wilayahmu.

Perubahan

Kami akan memperbarui kebijakan ini jika game mengubah data yang diprosesnya. Versi dan tanggal berlaku tercantum di bagian atas; perubahan penting diumumkan di dalam game.
