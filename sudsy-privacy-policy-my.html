ကိုယ်ရေးလုံခြုံမှု မူဝါဒ

Sudsy: Idle Car Wash Tycoon · ဗားရှင်း 1.0 · အသက်ဝင်သည့်နေ့ 2026 ခုနှစ် နိုဝင်ဘာလ 21 ရက်

ဤမူဝါဒသည် Sudsy: Idle Car Wash Tycoon ဂိမ်း ("ဂိမ်း") က မည်သည့်ဒေတာများကို အဘယ်ကြောင့် စီမံဆောင်ရွက်သည်နှင့် ယင်းနှင့်ပတ်သက်၍ သင် ဘာလုပ်နိုင်သည်ကို ရှင်းပြထားသည်။ ဘာသာပြန်ချက်သည် အင်္ဂလိပ်ဗားရှင်းနှင့် ကွဲလွဲပါက အင်္ဂလိပ်ဗားရှင်းကို အတည်ယူမည်။

ကျွန်ုပ်တို့ မည်သူဖြစ်သနည်း

ဤဂိမ်းကို Lagom Labs ("ကျွန်ုပ်တို့") က ထုတ်ဝေသည်။ ဆက်သွယ်ရန်: lagomlabs@gmail.com။

ဂိမ်းက စုဆောင်းသည့်အရာများ

  • ဂိမ်းအတွင်း ဖြစ်ရပ်များ (Firebase Analytics)။ ပြီးဆုံးသွားသော ကားဆေးမှုများ (ကား၊ အရည်အသွေး၊ လက်ဖြင့် သို့မဟုတ် ဝန်ထမ်းအဖွဲ့ဖြင့်၊ ကြာချိန်)၊ စခန်း အဆင့်မြှင့်မှုများ၊ ဝန်ထမ်းငှားရမ်းမှုများ၊ တိုက်ရိုက်ပွဲများ၊ သင်ခန်းစာ အဆင့်များ၊ ဆုလာဘ်ကြော်ငြာ ကမ်းလှမ်းမှုများနှင့် အဆုံးထိ ကြည့်ပြီးမှုများ၊ ဆိုင်ကြည့်ရှုမှုများနှင့် ဝယ်ယူမှုများ (ထုတ်ကုန် ID)၊ ဖရန်ချိုက်စ် ရောင်းချမှုများ၊ အော့ဖ်လိုင်းဝင်ငွေ ရယူမှုများ၊ cloud သိမ်းဆည်းမှု ရလဒ်များ၊ အသိပေးချက် ခွင့်ပြုချက်နှင့် ဖွင့်ကြည့်မှုများ ကဲ့သို့သော ဖြစ်ရပ်များကို ကျပန်း app-instance ID တစ်ခု၊ အခြေခံ စက်ပစ္စည်းနှင့် app အချက်အလက်များ (မော်ဒယ်၊ OS ဗားရှင်း၊ ဘာသာစကား၊ IP လိပ်စာမှ ဆုံးဖြတ်သော နိုင်ငံ၊ app ဗားရှင်း) နှင့်အတူ စုဆောင်းပြီး ပထမဆုံးအကြိမ် စတင်ချိန်တွင် Google Play install referrer (မည်သည့် စတိုးစာမျက်နှာ သို့မဟုတ် ကင်ပိန်းက ထည့်သွင်းမှုဆီ ဦးတည်စေသည်) ကိုလည်း စုဆောင်းသည်။ ဂိမ်းက စတိုးတွင် အဆင့်သတ်မှတ်ပေးရန် တောင်းဆိုသည့်အခါကိုလည်း ကျွန်ုပ်တို့ မှတ်တမ်းတင်သည်။ သဘောတူခွင့်ပြုချက် အဆင့်က ခွင့်မပြုမချင်း စုဆောင်းမှုကို ပိတ်ထားပြီး ဆက်တင် → အသုံးပြုမှု စာရင်းအင်း တွင် အချိန်မရွေး ပိတ်နိုင်သည်။ Analytics သည် သင်၏ ကြော်ငြာ ID သို့မဟုတ် Android ID ကို မစုဆောင်းပါ။
  • ပျက်စီးမှု အစီရင်ခံစာများ (Firebase Crashlytics)။ ဂိမ်း ပျက်သွားသည့်အခါ: ချို့ယွင်းချက်များကို ရှာဖွေပြင်ဆင်ရန် ပျက်စီးမှု မှတ်တမ်း (crash trace)၊ စက်ပစ္စည်း မော်ဒယ်၊ OS ဗားရှင်း၊ လွတ်နေသော မှတ်ဉာဏ်နှင့် ကျပန်း Crashlytics ထည့်သွင်းမှု ID တစ်ခု။
  • အဝေးမှ ဆက်တင်များ (Firebase Remote Config)။ ဂိမ်းသည် ဂိမ်းမျှတမှု တန်ဖိုးများကို ဒေါင်းလုဒ်လုပ်သည်။ ယင်းအတွက် ကျပန်း Firebase ထည့်သွင်းမှု ID တစ်ခုကို အသုံးပြုသည်။
  • ကြော်ငြာများ (Google AdMob)။ ဂိမ်းသည် သင်ကိုယ်တိုင် ကြည့်ရန် ရွေးချယ်သော ဆုလာဘ်ကြော်ငြာများကိုသာ ပြသသည်။ ယင်းတို့ကို ပြသရန် AdMob သည် သင့်စက်ပစ္စည်း၏ ကြော်ငြာ ID၊ IP လိပ်စာနှင့် စက်ပစ္စည်း အချက်အလက်များကို စီမံဆောင်ရွက်သည်။ EEA၊ ယူကေနှင့် လိုအပ်သော အခြားဒေသများတွင် Google ၏ သဘောတူခွင့်ပြုချက် ပုံစံက သင့်ကို ဦးစွာ မေးမြန်းမည်။ သင်၏ သဘောတူခွင့်ပြုချက် မရှိပါက ကြော်ငြာများသည် ကိုယ်ပိုင်စိတ်ကြိုက် မဟုတ်သော ကြော်ငြာများ ဖြစ်မည်။
  • Cloud သိမ်းဆည်းမှု (Google Play Games Services)။ သင် Google Play Games သို့ ဝင်ရောက်ထားပါက သင်၏ Play Games ကစားသမား ID နှင့် ဂိမ်းတိုးတက်မှု (save ဖိုင်) ကို အခြားစက်ပစ္စည်းတွင် ဆက်ကစားနိုင်ရန် သင်၏ Google အကောင့်တွင် သိမ်းဆည်းထားသည်။
  • ဝယ်ယူမှုများ (Google Play Billing)။ ငွေပေးချေမှုများကို Google Play က လုံးဝ ကိုင်တွယ်သည်။ ဂိမ်းသည် ဝယ်ယူမှု မှတ်တမ်း (ထုတ်ကုန် ID၊ အော်ဒါနှင့် ဝယ်ယူမှု token) ကိုသာ ရရှိပြီး သင်၏ ကတ် သို့မဟုတ် ဘဏ်အချက်အလက်များကို ဘယ်တော့မှ မမြင်ရပါ။
  • အသိပေးချက်များ (Firebase Cloud Messaging)။ သင် အသိပေးချက်များကို ခွင့်ပြုမှသာ စက်ပစ္စည်းသည် messaging token တစ်ခု ရရှိပြီး သင်၏ ဂိမ်းဘာသာစကားအတွက် သတင်းခေါင်းစဉ်တစ်ခု (ဥပမာ "lang_my") သို့ စာရင်းသွင်းခံရသည်။ "ငွေသေတ္တာ ပြည့်ပြီ" ကဲ့သို့သော သတိပေးချက်များကို သင့်စက်ပစ္စည်းပေါ်တွင် စီစဉ်ထားပြီး မည်သည့်ဒေတာမျှ မပို့ပါ။
  • အဆင့်သတ်မှတ်ချက်များ (Google Play In-App Review)။ ပျော်ရွှင်ဖွယ် အခိုက်အတန့်တစ်ခုအပြီးတွင် ဂိမ်းက Google Play ၏ အဆင့်သတ်မှတ်ကတ်ကို ပြသနိုင်သည်။ ယင်းပေါ်မပေါ်ကို Google က ဆုံးဖြတ်သည်။ သင် အဆင့်သတ်မှတ်ခဲ့ခြင်း ရှိမရှိ သို့မဟုတ် မည်သို့ သတ်မှတ်ခဲ့သည်ကို ဂိမ်းက ဘယ်တော့မှ မသိရပါ။
  • သင့်စက်ပစ္စည်းပေါ်တွင်။ သင်၏ တိုးတက်မှုနှင့် ဆက်တင်များကို စက်ပစ္စည်းပေါ်တွင် သိမ်းဆည်းထားသည်။

ဂိမ်းက မစုဆောင်းသည့်အရာများ

သင်၏ အမည်၊ အီးမေးလ်လိပ်စာ၊ ဖုန်းနံပါတ်၊ တိကျသော တည်နေရာ၊ အဆက်အသွယ်များ၊ ဓာတ်ပုံများ၊ ဖိုင်များ သို့မဟုတ် မိုက်ခရိုဖုန်း။ ဂိမ်းသည် ဤခွင့်ပြုချက်များကို မတောင်းခံပါ။ ဂိမ်းကိုယ်တိုင် တောင်းခံသည့်အရာများ: အင်တာနက် အသုံးပြုခွင့်၊ ကွန်ရက် အခြေအနေ၊ တုန်ခါမှု၊ အသိပေးချက်များ (Android 13+၊ မဖြစ်မနေ မဟုတ်)၊ စက်ကို ပြန်စ (reboot) ပြီးနောက် သတိပေးချက်များ ပြန်စတင်ခြင်း၊ ကြော်ငြာ ID (ကြော်ငြာများအတွက်) နှင့် Google Play billing။ ဂိမ်းအတွင်းရှိ Google ၏ library များက ထပ်ထည့်သည့်အရာများ: နောက်ခံလုပ်ငန်းများအတွက် စက်ကို ခဏတာ နိုးကြားနေစေခြင်း၊ push မက်ဆေ့ချ်များ လက်ခံခြင်း၊ Play install referrer ကို ဖတ်ခြင်း၊ Android ကြော်ငြာဝန်ဆောင်မှု၏ attribution နှင့် ad ID API များ၊ အခြေခံ ဖုန်းအခြေအနေ (ကွန်ရက် အမျိုးအစား၊ ကြော်ငြာများက အသုံးပြုသည်) နှင့် Google ၏ နောက်ခံလုပ်ငန်းအတွက် foreground service တစ်ခု။ ယင်းတို့အနက် မည်သည့်အရာကမျှ မျက်နှာပြင်ပေါ်တွင် သင့်ထံ ဘာမျှ မတောင်းခံဘဲ သင်၏ ဖုန်းခေါ်ဆိုမှုများ၊ မက်ဆေ့ချ်များ သို့မဟုတ် ဖိုင်များကို အသုံးပြုခွင့်လည်း မပေးပါ။

ကျွန်ုပ်တို့ အဘယ်ကြောင့် အသုံးပြုသနည်း

ဂိမ်းကို လည်ပတ်ပြီး သင်၏ တိုးတက်မှုကို သိမ်းဆည်းရန်၊ စက်ပစ္စည်းအသစ်တွင် ပြန်လည်ရယူရန်၊ ပျက်စီးမှုများကို ရှာဖွေပြင်ဆင်ရန်၊ ဂိမ်းကို မျှတအောင် ချိန်ညှိရန်၊ သင်ရွေးချယ်သော ဆုလာဘ်ကြော်ငြာများကို ပြသရန်နှင့် သင်ဝယ်ယူသည့်အရာများကို ပေးပို့ရန်။

ပြင်ပအဖွဲ့အစည်းများ

အထက်ပါ ဝန်ဆောင်မှုအားလုံးကို Google က ပံ့ပိုးသည်: Firebase Analytics, Crashlytics, Remote Config နှင့် Cloud Messaging (firebase.google.com/support/privacy)၊ AdMob (policies.google.com/technologies/ads)၊ Google Play Games Services နှင့် Google Play Billing (policies.google.com/privacy)။ ကျွန်ုပ်တို့သည် သင်၏ဒေတာကို မရောင်းချသလို အခြားမည်သူနှင့်မျှလည်း မမျှဝေပါ။

သဘောတူခွင့်ပြုချက်နှင့် သင်၏ ရွေးချယ်မှုများ

  • လိုအပ်သည့်နေရာများတွင် ပထမဆုံးအကြိမ် ဖွင့်ချိန်၌ သဘောတူခွင့်ပြုချက် ပုံစံ ပေါ်လာမည်။ ဆက်တင် → ကိုယ်ရေးလုံခြုံမှု ရွေးချယ်စရာ တွင် အချိန်မရွေး ပြန်ဖွင့်နိုင်သည်။
  • ဆက်တင် → အသုံးပြုမှု စာရင်းအင်း တွင် အသုံးပြုမှု စာရင်းအင်းကို ပိတ်နိုင်သည်။
  • ဆက်တင် သို့မဟုတ် Android ဆက်တင်များတွင် အသိပေးချက်များကို ချန်နယ်အလိုက် ပိတ်နိုင်သည်။
  • သင်၏ Android ဆက်တင်များ (Google → ကြော်ငြာများ) တွင် ကိုယ်ပိုင်စိတ်ကြိုက် ကြော်ငြာများကို ငြင်းပယ်နိုင်သည်။
